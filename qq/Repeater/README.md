# repeater 插件

群聊复读机：相同文本消息（相隔不超过 2 条）时，机器人立刻复读一次。

自包含插件，不依赖共享 core/ 包。

## 功能

- 群聊中「相同文本」消息出现（相隔不超过 2 条，即 AA / ABA / ABCA 均触发）时，机器人立刻发送一条相同内容的纯文本消息
- 不要求来自不同的人：同一人连发两条相同内容也算复读
- 每段相同内容只复读一次：复读后直到出现不同内容才重置，防止无限刷屏
- 按群隔离状态；非文本消息（图片/表情/纯 @）会打断窗口
- 忽略机器人自身的消息，避免自回环

## 配置

- config.yaml：enabled（总开关，默认 true）。首次使用复制 configExample.yaml 为 config.yaml。

修改 .yaml 后需 docker restart ncatbot 才生效（FileWatcher 只监听 .py）。

## 部署注意

插件自包含，不依赖 core 包，直接复制 qq/Repeater/ 到容器 plugins/Repeater/ 即可。

## 说明

- 「相同内容」按纯文本比较（剥离 @/图片/表情/引用，去首尾空白）。
- 复读发送的是纯文本消息（不带 @、不引用原消息）。
- 状态不持久化：热重载后丢失「上一条」，最多错过一次复读机会。
- 已知边缘：若某条 @机器人 的消息恰好与前一条文本相同，复读机与 ai_chat 的 LLM 问答会同时响应。
